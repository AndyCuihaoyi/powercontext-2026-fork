        量化与推理后端基准

        同一语料、同一评估集，对比模型体积、质量与分阶段延迟

        基准会在浏览器内分别加载所选模型精度，把 24 篇示例文档导入临时集合（每个变体独立）， 用 22 条标注查询计算文档级 Recall@5 / Recall@10 / nDCG@10，同时记录模型加载、 文档向量化、索引刷新、查询向量化与 seekdb 检索的耗时。结束后临时集合会自动删除。

        首次运行会重复加载模型，耗时约 1–3 分钟

        一页技术说明

        这是一个纯本地推理的迷你知识库：文档切块与 embedding 全部在浏览器内完成 （Transformers.js + ONNX Runtime Web），向量、原文与元数据写入本地 seekdb， 检索调用 seekdb-js 的 hybridSearch，由数据库通过 DBMS_HYBRID_SEARCH.GET_SQL 生成一条融合 SQL 并执行 RRF。 应用层不会分别拉取两路结果再自行拼合。

        模型与量化

        推理后端

        启动时探测 navigator.gpu：可用则优先 WebGPU + FP16，若设备不支持 FP16 依次回退 WebGPU + INT8、WASM + INT8；WebGPU 不可用则直接使用 WASM + INT8。 所有切换都会在右上角标注实际后端与精度。访问 ?backend=wasm 可强制降级。 模型与 ONNX Runtime 的 WASM 文件均由本机静态目录提供，运行期不访问云端推理服务。

        seekdb 数据层

        • 每个集合对应一个 seekdb collection：FULLTEXT ... WITH PARSER ik + HNSW（512 维，cosine）。
        • 应用元数据表（stepfun_*）记录集合、文档、索引刷新状态与会话。
        • 导入时浏览器提交分块与向量；服务端校验正文哈希、分块子串与向量归一化后批量写入。
        • 批量导入完成后调用一次 refresh_index()，并用新文档的独特片段做全文探测，确认刷新后可检索。
        • 删除文档会清理其块并刷新索引；集合切换与最近查询写入会话，刷新页面后恢复。

        边界与红线

        • 不调用任何云端推理 API；运行期浏览器请求只指向本机静态资源与本地 API。
        • 不在服务端预计算或回放向量；服务端只做校验、持久化与数据库检索。
        • 不使用客户端内存检索或两路结果手工拼接替代数据库混合检索。
        • 模型权重不进入仓库；npm run models:fetch 按锁定 revision 与 SHA-256 下载。
